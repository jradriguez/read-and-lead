# Read and Lead

Read README.md, docs/design.md and docs/implementation-plan.md before changes.
Expo SDK 57: read https://docs.expo.dev/versions/v57.0.0/ for native API changes.
Work inline on a feature branch; preserve unrelated edits. Keep strict TypeScript,
parameterized SQL and offline bundled content. Do not add services or dependencies
without a concrete need. No child identifiers, recordings, credentials or private
family observations in Git. No live AI, ads, microphone, billing or network lessons
in M1. Content approval requires human review; never mark draft teaching material
approved to pass a test. A passing code gate is not a released curriculum.
Run npm run validate:code and git diff --check for changes; npm run validate and
npm run security:check before release. Document unavailable native/device evidence.
No remote push, signing-account change, purchase or store submission is implied.
